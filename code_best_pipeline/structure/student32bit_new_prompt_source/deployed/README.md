# Frozen32-bit teacher -> new prompt source -> rank32 student

The teacher is the original SD2.1 Structure32 refine600 checkpoint (SHA256 `2f9fc8d664786acfe50bf7d47c20e037a92e4cc61805524233bd7f15f365a2d8`), not the later manipulation-trained teacher. No teacher retraining, key/carrier change or watermark manipulation occurs.

Prompts come from [Gustavosta/Stable-Diffusion-Prompts](https://huggingface.co/datasets/Gustavosta/Stable-Diffusion-Prompts) revision `f40484704ca5bdeb389483123ba017897f1bfcdc`. Select5000train+1000validation from its train.parquet and1000test from eval.parquet. Stable seeded selection, short/explicit-content keyword exclusions, casefolded NFKC text deduplication, and deduplication of effective77token sequences for BOTH SD2.1/SD1.4 tokenizers run across all new splits and all12000old COCO prompts. This is prompt-source shift from the teacher/carrier's COCO source, not proof of novelty relative to SD pretraining; lexical/semantic near duplicates remain possible. Keyword filtering is not a comprehensive content classifier. Input parquet hashes and source row indices are saved.

Teacher generates5000unmanipulated training images. It also generates1000validation+1000test watermarked images and paired clean controls. The base SD1.4 generates an unadapted1000test control. Generation uses unchanged50step native scheduler/CFG7.5/pinned weights, deterministic prompt IDs/seeds. GPU1 handles teacher train generation;GPU0 handles heldout/control generation in parallel. The original teacher's adapter/merged weights are read-only shared paths. Native teacher pipeline hash checks and frozen output manifests apply.

Student starts fresh clean SD1.4 rank32 attention+convolution LoRA, batch4, seed0, ordinary denoising MSE, no owner/detector loss. Identical LR schedule to previous studies:1e-4 through7500, cosine to2e-5 at12500, then constant2e-5 to20000. Real4step smoke before full training, loss/update logging, complete optimizer/scaler/Python/NumPy/TorchCPU/CUDARNG states every1250steps. AMP skipped counts are retained in reports. Final20000 checkpoint is fixed, with no validation/test selection.

Student/teacher evaluation uses only the new heldout1000test prompts. Original COCO carrier, key and thresholds remain frozen; no new-data calibration. Report BA, exact32/32 recovery and acceptance≥24/32 for groups1/8/32/64/256, plus per-bit margins. Conditional theoretical binomial false acceptance is0.350018%; not an empirically verified null FPR.100 random partitions reuse images, so group counts are not independent trials. Also retain paired student-vs-unadaptedLPIPS and CLIP/FID/KID with new prompt-source clean controls.

Server `.21`, root `/var/lib/structure32_newprompts_rank32`. `status.json` tracks preparation/generation/student stages. Code, prompt IDs, provenance, config and checkpoint identity should be kept together. Drop96 review was explicitly stopped and is unrelated to this experiment.
